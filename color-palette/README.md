# 拼豆色板数据

## 数据来源

### MARD 标准色（221 色）
- **来源**：[kooriookami.github.io/pindou](https://kooriookami.github.io/pindou/)
- **文件**：`mard-221.json`
- **说明**：基于官方色卡提取的 HEX 色值，覆盖 9 个系列

### Artkal S 系列（60 色精简版）
- **来源**：[sucpyy/perler-pattern](https://github.com/sucpyy/perler-pattern)
- **文件**：`artkal-s-60.json`
- **说明**：最常用的精简色板，适合图像识别场景

## 使用建议

### 图像识别场景
- **推荐使用**：Artkal S 60 色精简版
- **原因**：颜色数量少，识别精度高，计算复杂度低
- **算法**：建议使用 CIELAB 色彩空间 + 欧氏距离

### 完整色板场景
- **推荐使用**：MARD 221 色标准版
- **原因**：覆盖完整，颜色还原度高
- **算法**：建议使用 CIEDE2000 色差公式
