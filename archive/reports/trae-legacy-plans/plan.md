# 拼豆图纸导出样式优化计划

## 1. 现状分析
当前项目在 `miniapp/pages/index/index.js` 中的 `_drawExportCanvas` 方法负责生成导出的拼豆图纸。目前的样式包括：
- 深色背景的表头（包含系统名称）。
- 灰蓝色背景的行列坐标轴。
- 带有灰色网格线的拼豆网格。
- 底部带有灰色圆角背景的颜色对照表（包含色块、色号和数量，分行显示）。

目标图片（参考图）的样式特点：
- **整体风格**：更加清爽、明亮，以白色为主基调。
- **表头**：白色背景，深色文字，包含标题、色板名称和总颗粒数，例如 `🎨 豆画 / Mard(265)`。
- **网格区域**：
  - **坐标轴**：白色背景，深色粗体数字。
  - **空网格**：浅灰色背景（如 `#F5F5F5`）。
  - **有颜色的网格**：对应颜色的背景。
  - **网格线**：纯白色（可以通过在白色底色上绘制稍小一圈的色块来实现，留出间隙作为网格线）。
- **图例（颜色对照表）**：
  - 极简风格，没有大背景框和标题。
  - 横向排列，格式为 `[颜色方块] 色号 (数量)`，例如 `■ F22 (118)`。

## 2. 修改方案
修改 `miniapp/pages/index/index.js` 中的 `_drawExportCanvas` 方法，重构 Canvas 的绘制逻辑：

### 2.1 表头 (Header)
- 移除深色背景，改为纯白背景 `#FFFFFF`。
- 修改文字内容为 `🎨 豆画 / ${currentSystem}(${exportTotal})`。
- 文字颜色改为 `#333333`，字号调大，左对齐。

### 2.2 坐标轴与网格 (Grid & Axes)
- 设定统一的间隙 `gap = 1` 或 `2` 像素，用于形成白色网格线。
- **坐标轴**：不绘制背景（或者绘制白色背景），直接居中绘制行列数字，文字颜色 `#333333`。
- **网格底色**：整个网格区域底层为 `#FFFFFF`。
- **单元格绘制**：
  - 如果是空单元格（无颜色），绘制大小为 `cell - gap` 的浅灰色矩形 `#F5F5F5`。
  - 如果是有颜色的单元格，绘制大小为 `cell - gap` 的对应颜色矩形。
  - 在有颜色的单元格中心绘制色号文字，颜色根据背景对比度自适应（现有逻辑保留），适当调整字号。

### 2.3 图例 (Legend)
- 移除“颜色对照表”标题和灰色的圆角背景框。
- 采用紧凑的流式布局（横向排列，自动换行）：
  - 每个图例项包含一个正方形色块（例如 16x16）和一段文字（例如 `F22 (118)`）。
  - 设定项与项之间的水平间距（如 20px）和垂直间距（如 10px）。
  - 文字颜色为黑色或深灰色。

## 3. 实施步骤
1. **清理旧绘制逻辑**：移除 `_drawExportCanvas` 中旧的表头背景、行列坐标轴背景、网格线绘制代码以及旧的图例绘制代码。
2. **重写表头和背景**：设置整体白色背景，绘制新格式的表头文本。
3. **重写坐标轴**：在顶部、底部、左侧、右侧绘制坐标数字。
4. **重写网格绘制**：双层循环遍历 `exportGrid`，计算每个格子的 `x`, `y` 坐标，使用 `fillRect` 绘制减去 `gap` 的矩形。如果单元格有颜色，则同时绘制文字。
5. **重写图例绘制**：遍历 `exportColorList`，动态计算每个图例项的 x 和 y 坐标并绘制色块和文字，超过最大宽度则换行。
6. **调整 Canvas 尺寸计算**：根据新的图例布局计算所需的 `footerH`，从而确定 Canvas 的总高度。

## 4. 假设与决策
- 假设空单元格在 `exportGrid` 中的标识为 `key === '?'` 或 `color === '#FFF'`（查看当前逻辑，空单元格确实是 `{color:'#FFF',key:'?'}`）。
- 决定采用填充缩小版矩形的方式来实现白色网格线，这比画线更平齐，并且能完美复刻参考图中“白色间隙”的效果。
- 参考图没有坐标轴的边框线，所以我们也会移除坐标轴外围的灰色边框。

## 5. 验证方式
- 在微信小程序开发者工具中运行，上传一张图片并点击“保存色卡图纸”。
- 检查导出的图片是否符合参考图的清爽白色风格、白色网格线以及简洁的图例排版。
