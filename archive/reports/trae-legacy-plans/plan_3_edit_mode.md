# 拼豆小程序 - 图纸可修改功能 (Edit Mode) 实现计划

## 1. 需求背景与目标
用户希望在生成拼豆图纸后，能够对不满意或有瑕疵的部分进行**手动修改**。
核心需求包括：
- **编辑模式开关**：开启后图纸变为可交互状态。
- **滑动多选**：手指在网格上滑动可以连续选中多个豆子，并显示半透明高亮遮罩。
- **删除与替换**：选中的豆子可以被删除（变为空白/透明），或者使用色板中的其他颜色进行替换。
- **撤销功能 (Undo)**：防止误操作，支持回退到上一步状态。

## 2. 当前状态分析
- 目前生成的图纸数据存储在 `this.data.gridData`（二维数组）中，纯静态展示，没有交互。
- 渲染使用原生 `<canvas canvas-id="gridCanvas">`，如果在该 canvas 上频繁触发重绘（例如滑动选中时），对于 50x50 甚至 100x100 的网格，性能开销极大，容易导致滑动卡顿。
- 颜色统计信息 (`colorList`, `totalCount`) 是在 `_pixelate` 阶段一次性计算好的，修改网格后需要有重新计算的机制。

## 3. 核心技术方案与修改点

### 3.1 界面层 (`index.wxml` & `index.wxss`)
- **双 Canvas 叠加架构**：
  - 在原有的 `gridCanvas` 之上，绝对定位叠加一层同等尺寸的 `<canvas canvas-id="overlayCanvas">`。
  - `overlayCanvas` 专门用于监听触摸事件 (`bindtouchstart`, `bindtouchmove`, `bindtouchend`)，并负责绘制半透明的选中高亮框。这样可以彻底避免滑动时重绘底层几千个格子的性能问题。
- **编辑模式工具栏**：
  - 增加一个「进入/退出编辑模式」的切换按钮。
  - 当处于编辑模式时，在图纸下方显示专属工具栏，包含：
    1. **操作按钮**：「撤销」、「清空选择」、「删除选中」。
    2. **颜色替换区**：横向滚动的色板列表（基于当前图纸使用的颜色或全量色板），点击其中一个颜色即可将选中的格子替换为该颜色。

### 3.2 逻辑层 (`index.js`)
- **新增状态 (Data)**：
  - `isEditMode`: `false` (是否处于编辑模式)
  - `selectedCells`: `[]` (当前选中的格子坐标，例如 `[{i: 0, j: 1}, ...]`)
  - `history`: `[]` (历史记录栈，存放 `gridData` 的深拷贝快照)
- **滑动选中逻辑**：
  - 在 `touchstart` 和 `touchmove` 中，获取 `e.touches[0].x` 和 `y`。
  - 根据当前的 `canvasWidth`、`canvasHeight` 以及网格的 `N`、`M`，计算出手指所在的行列索引 `(i, j)`。
  - 将 `(i, j)` 加入 `selectedCells`（需去重）。
  - 调用 `_drawOverlay()` 在 `overlayCanvas` 上绘制高亮遮罩。
- **修改与历史记录逻辑**：
  - **保存快照**：每次执行“删除”或“替换”前，将当前的 `gridData` 深拷贝压入 `history` 数组（限制最大 20 步）。
  - **删除**：遍历 `selectedCells`，将 `gridData[j][i]` 设置为 `{ color: '#FFFFFF', key: '?' }`。
  - **替换**：遍历 `selectedCells`，将 `gridData[j][i]` 设置为目标颜色。
  - **撤销**：从 `history` `pop()` 出上一个状态，赋值给 `gridData`，清空 `selectedCells`。
  - **更新视图与统计**：操作完成后，调用 `_drawGrid()` 重绘底层网格，并调用新增的 `_recalculateStats()` 方法重新统计颜色数量，更新 `colorList` 和 `totalCount`。

### 3.3 工具方法抽取
- 将原本在 `_pixelate` 中的颜色统计逻辑抽离为独立的 `_recalculateStats(grid)` 方法，以便在每次修改网格后复用。

## 4. 假设与约束
- **性能优化**：通过使用独立的 `overlayCanvas` 承载交互视觉，保证滑动选择的帧率。
- **边界处理**：手指滑出 canvas 边界时的坐标需要做 `Math.max/min` 截断，防止数组越界报错。
- **空白格定义**：被删除的格子其 `key` 为 `'?'`，在统计颜色和导出图纸时会被识别为留白，不会消耗实际的拼豆。

## 5. 验收标准
1. 点击“编辑”进入交互模式，图纸上方出现编辑工具栏。
2. 手指在图纸上滑动，能顺滑地画出蓝色半透明选中区域。
3. 点击“删除”，选中的格子变白；点击下方某个颜色，选中的格子变为该颜色。
4. 每次修改后，颜色统计列表（各颜色数量、总消耗数）会实时精确更新。
5. 点击“撤销”，图纸和统计数据能完美恢复到上一步状态。
